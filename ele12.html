Bahasa Pemrograman untuk Web Interaktif

Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi dinamis dan interaktif. Dengan JavaScript, kamu dapat menambahkan animasi, memvalidasi form, menampilkan data secara real-time, dan banyak lagi.

Contoh Kode JavaScript

Berikut contoh sederhana untuk menampilkan pesan di konsol:

console.log("Halo, JavaScript!");

Atau menampilkan pesan di halaman web:

document.write("Selamat datang di dunia JavaScript!");
